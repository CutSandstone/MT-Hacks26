# What Would Hedge This? — MT-haCks 2026 Fintech

Open `What Would Hedge This - Pitch Deck.html` directly in a browser to present the seven-slide deck. It works offline; every slide carries an animated Three.js visual, and slide 5 is an interactive example (choose $0/$1,000/$2,000 to convert and watch the uncovered amount change). Use the on-screen controls, arrow keys, Space, Home, or End.

The editable PowerPoint and static PDF are next to the HTML deck. `What Would Hedge This - Demo.mp4` is the ~1:46 narrated product walkthrough (yen tuition scenario, plus intro, guardrails, and closing). Load the accompanying `.srt` file if the video player does not pick up captions automatically.

## Generation sources

- [Deck](source/deck/README.md): slide layout, Three.js player, styling, and build commands.
- [Video](source/video/README.md): original app recording, rendered voiceover, narration text, title cards, and build commands. The included audio is sufficient to rebuild the video without access to ElevenLabs.

Run `npm start` from the repository root to try the prototype. The demo uses hypothetical figures, shows what changes under each scenario, and places no trades.
