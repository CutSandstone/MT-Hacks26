# Demo video generation sources

Everything needed to reproduce `What Would Hedge This - Demo.mp4` (~1:46 /
106.1 s, 1920x1080 H264 + AAC) and `What Would Hedge This - Captions.srt`.
The shipped cut is yen-only: hook, the full yen tuition walkthrough,
guardrails, and conclusion. The bundled `raw/demo.webm` + `raw/markers.json`
retain the original career walkthrough (markers `beat2`-`beat4`) and
`beats/beat2.mp3`, `beat3.mp3` narration for reproducibility.

## Contents

- `record.cjs` — Playwright capture script. Drives the real app at
  `DEMO_URL` (default `http://localhost:8766/`, serve the app with
  `PORT=8766 npm start` from the repo root) through the cybersecurity and yen
  scenarios with a visible cursor overlay. Writes `raw/regenerated.webm` and
  `raw/regenerated-markers.json`; it does **not** overwrite the original take.
- `raw/demo.webm` — the original 77.6 s Playwright take used in the submission.
- `raw/markers.json` — timestamps (seconds into the take) marking the segment
  boundaries: `beat2` entry screen, `beat3` cyber result, `beat4` yen survey
  start, `beat5` yen result, `end`.
- `shots.cjs` — screenshots the slide card HTML to `slides/*.png`.
- `slides/` — authored title/closing/assumptions cards (HTML + `base.css`),
  warm-ivory/ink/forest/lime/rust editorial style. PNGs are derived artifacts
  and regenerated by `shots.cjs`.
- `beats/beat{1..7}.txt` — narration script (input text).
- `beats/beat{1..7}.mp3` — rendered narration used in the submission
  (ElevenLabs, voice `nPczCjzI2devNBz1zQrb` "Brian", `eleven_multilingual_v2`).
- `tts.py` — regenerates `beats/*.mp3` from the txt files. Requires
  `ELEVENLABS_API_KEY` (and optionally `ELEVENLABS_VOICE_ID`) in the
  environment; exits cleanly without it. Not needed for a rebuild since the
  rendered MP3s are bundled.
- `render.py` — the exact assembly recipe (`KEEP_BEATS = (1, 4, 5, 6, 7)`, scene timings, zoompan card clips,
  segment cut + speed-conform, narration padding, concat, faststart mux, SRT
  generation). Writes `out/final.mp4` and `out/captions.srt`.

## Rebuild (no credentials required)

```sh
cd submission/source/video
npm install          # playwright 1.64.0, only needed to re-screenshot slides
python3 render.py    # -> out/final.mp4, out/captions.srt
```

`render.py` uses the bundled `raw/demo.webm`, `raw/markers.json` and
`beats/*.mp3`. If `slides/*.png` are absent it runs `node shots.cjs` first.

## Re-capture app footage (optional)

```sh
PORT=8766 npm start          # from the repo root, in another shell
cd submission/source/video
npm install && npm run capture
```

Produces `raw/regenerated.webm` + `raw/regenerated-markers.json`. To cut a new
edit from a regenerated take, point `render.py`'s `RAW`/`MARKERS` at those
files (the submitted cut uses `demo.webm` + `markers.json`).

## Notes

- No secrets are stored here; TTS reads the key from the environment only.
- Verified: `ffprobe` on the rendered file reports h264 1920x1080 + aac,
  duration ~106.1 s. On-screen figures match narration (-$800/-$600
  then -$400 yen matrix after changing the convert amount to $2,000).
